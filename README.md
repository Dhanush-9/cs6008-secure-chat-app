# CS6008 — Secure Chat Application

A TCP chat app built in five phases: plaintext baseline → Diffie–Hellman + AES-GCM →
PKI-based server authentication → end-to-end encryption → forward secrecy.

Each phase lives in its own directory (`phase1/` … `phase5/`) with its own README.
Full writeup in the report PDF.
